# ORM Generator 使用範例

這是一個從 Proto 定義生成 GORM model struct 的生成器。

## 功能特性

1. **Proto 類型到 Go 類型的映射**
   - 支援所有基本類型 (int, string, bool, float, etc.)
   - 支援時間類型 (timestamp, datetime, date)
   - 支援二進位類型 (bytes, []byte)
   - 支援陣列類型，自動轉換為 Go slice

2. **GORM 標籤自動生成**
   - 自動設定 `column` 標籤對應欄位名稱
   - 自動標記第一個欄位為 `primaryKey`
   - 陣列欄位自動加上 `serializer:json`
   - 自動生成 JSON 標籤（snake_case 格式）

3. **TableName 方法**
   - 自動生成 `TableName()` 方法，指定表名

4. **自定義類型映射**
   - 支援透過選項函數擴展類型映射

## 程式碼範例

```go
package main

import (
    "fmt"
    "github.com/miskawu/formgen/internal/generator/orm"
    "github.com/miskawu/formgen/internal/schema"
)

func main() {
    // 建立一個實體定義
    entity := schema.Entity{
        Name: "User",
        Columns: []schema.Column{
            {Name: "id", RawType: "int64", IsArray: false},
            {Name: "name", RawType: "string", IsArray: false},
            {Name: "email", RawType: "string", IsArray: false},
            {Name: "age", RawType: "int", IsArray: false},
            {Name: "isActive", RawType: "bool", IsArray: false},
            {Name: "tags", RawType: "string", IsArray: true},
            {Name: "createdAt", RawType: "timestamp", IsArray: false},
        },
    }

    // 使用預設選項建立生成器
    gen := orm.New()

    // 生成 GORM model
    output, err := gen.Generate([]schema.Entity{entity})
    if err != nil {
        panic(err)
    }

    fmt.Println(string(output))
}
```

## 生成結果

上面的程式碼會生成以下 GORM model：

```go
package models

// User GORM model
type User struct {
    Id int64 `gorm:"column:id;primaryKey" json:"id"`
    Name string `gorm:"column:name" json:"name"`
    Email string `gorm:"column:email" json:"email"`
    Age int `gorm:"column:age" json:"age"`
    IsActive bool `gorm:"column:isActive" json:"is_active"`
    Tags []string `gorm:"column:tags;serializer:json" json:"tags"`
    CreatedAt time.Time `gorm:"column:createdAt" json:"created_at"`
}

// TableName specifies the table name for GORM
func (User) TableName() string {
    return "User"
}
```

## 自定義選項

所有配置選項定義在 [options.go](options.go) 中。

### 自定義 Package Name

預設的 package name 是 `models`，可以使用 `WithPackageName` 選項自定義：

```go
// 使用自定義 package name
gen := orm.New(orm.WithPackageName("entities"))
```

生成結果：

```go
package entities

// User GORM model
type User struct {
    // ...
}
```

### 自定義類型映射

如果需要自定義類型映射，可以使用 `WithCustomMappings` 選項：

```go
customMappings := map[string]string{
    "entry": "int32",
    "userId": "string",
}

gen := orm.New(orm.WithCustomMappings(customMappings))
```

### 組合多個選項

可以同時使用多個選項：

```go
gen := orm.New(
    orm.WithPackageName("models"),
    orm.WithCustomMappings(map[string]string{
        "entry": "int32",
        "userId": "string",
    }),
)
```

### 生成 ToProto 方法

如果需要在 GORM model 中生成 `ToProto()` 方法來轉換為 Protocol Buffer 消息，可以使用 `WithProtoPackage` 選項：

```go
gen := orm.New(
    orm.WithProtoPackage("github.com/yourproject/proto", "pb"),
)
```

生成結果：

```go
// Code generated by formgen. DO NOT EDIT.
package models

import (
    pb "github.com/yourproject/proto"
)

// User GORM model
type User struct {
    Id   int64  `gorm:"column:id;primaryKey" json:"id"`
    Name string `gorm:"column:name" json:"name"`
}

// TableName specifies the table name for GORM
func (User) TableName() string {
    return "User"
}

// ToProto converts the GORM model to proto message
func (m *User) ToProto() *pb.User {
    if m == nil {
        return nil
    }
    return &pb.User{
        Id:   m.Id,
        Name: m.Name,
    }
}
```

**參數說明**：
- `importPath`: Proto package 的完整 import 路徑，例如 `"github.com/yourproject/proto"`
- `alias`: Proto package 的別名，例如 `"pb"`。如果為空字串則不使用別名
```

## 測試

執行測試：

```bash
go test ./internal/generator/orm/... -v
```

所有測試包含：
- 類型映射測試
- 基本 model 生成測試
- 陣列類型處理測試
- 自定義映射測試
- 混合類型測試
- bytes 類型陣列測試
- 輔助函數測試 (toPascalCase, toSnakeCase, buildGormTag)
